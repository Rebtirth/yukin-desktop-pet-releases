# 雪乃桌宠 v1.0.0

一个安静的 Windows Q 版桌面挂件：眨眼、切换表情、打瞌睡，偶尔用文字陪伴你。

这是非官方同人学习项目。本页面仅发布成品，未开放源代码。

## 下载与运行

1. 在 GitHub Releases 的附件中下载 `YukinDesktopPet-v1.0.0-win-x64.zip`。自动生成的 `Source code` 压缩包不是桌宠程序。
2. 解压到自己有写入权限的文件夹，再双击 `YukinDesktopPet-quiet.exe`，不要在压缩包内直接运行。
3. 需要 64 位 Windows 和 .NET Framework 4.8。无需安装 Python、开发工具或大模型。

程序为便携版，图片与图标已嵌入 EXE。不需要管理员权限，不联网，不使用 API，也不消耗模型 token。目前只有文字气泡，没有语音或自由聊天。

## 操作

- 左键单击：唤醒、切换表情。
- 按住左键拖动：移动位置。
- 右键：选择表情、置顶、开启或关闭“偶尔说句话”、手动“说一句话”、退出。
- 系统托盘：显示、隐藏或退出。
- 再次双击 EXE：唤回已经运行的桌宠。测试其他版本前，请先退出已有桌宠，以免唤回旧版。

## 自动行为

- 清醒时每 30–60 秒随机切换平静、微笑、思考；每 3–6 秒眨眼。
- 90–150 秒没有操作桌宠后困倦 3 秒，再睡眠 2 分钟；自然醒后至少清醒 3 分钟。
- 手动选择的表情保持约 15 秒；点击、拖动和菜单交互可唤醒。
- 默认每 3–5 分钟安排一句本地短句，气泡停留 8 秒。手动说话不重置自动计时。
- 困倦、睡眠或正在交互时，自动气泡会延后；睡醒后最多补发一句。因此不是严格每隔 3–5 分钟都能看到气泡。首次持续无互动时，通常约 3 分 33 秒至 5 分钟出现首条台词。

“无操作”只指没有与桌宠互动，不监控其他应用的键盘鼠标。当前大小固定为 155 × 165 WPF 单位，实际像素随 Windows 缩放变化。
